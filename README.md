# HR 꾸러미

HRM·HRD 용어와 트렌드를 한국어/영어로 넘겨 보는 도트 스타일 HR 공부 앱입니다.

- 사이트: https://hrsohee.github.io/hr-kkureomi/
- 핸드폰에서 열고 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있어요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 전체 (화면, 용어, 퀴즈, 즐겨찾기) |
| `trends.json` | 트렌드 카드. 매주 월요일에 새 소식이 있으면 추가돼요 |
| `manifest.webmanifest` | 홈 화면에 추가했을 때의 앱 이름, 아이콘, 색상 |
| `sw.js` | 한 번 연 뒤에는 인터넷 없이도 볼 수 있게 해 줘요 |
| `icons/` | 도트 장바구니 앱 아이콘 |
| `tools/make-icons.ps1` | 아이콘을 다시 그리는 도구 |
| `tools/serve.ps1` | 올리기 전에 내 컴퓨터에서 미리 보는 도구 (`http://localhost:8765/`) |

## 트렌드 규칙

- 반기(1~6월, 7~12월) 동안 쌓이고, 새 반기가 되면 지난 반기 카드는 보이지 않아요.
- 새 카드가 맨 앞에 와요.
- 즐겨찾기는 각자 기기에만 저장돼요.
